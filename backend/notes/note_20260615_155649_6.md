# 任务 2: UAV巡检安全风险

任务概览：梳理无人机巡检传输线时的主要安全风险（如碰撞、电磁干扰、环境因素）及现有防护措施。
来源概览：
1. Dianovský (2023) - TRID: 研究高压线电磁辐射对UAV飞行安全与性能的影响，指出碰撞与电磁干扰是主要挑战。
2. Dianovský (2023) - ScienceDirect: 同上研究，强调碰撞与电磁干扰。
3. Scribd文档: 研究高压线电磁辐射对UAV飞行安全与性能的影响，提出安全操作指南与UAV设计改进。
4. Boukabou (2024) - ADS/MDPI: 电场与磁场安全分析，结论是需要精确距离考量以确保UAV安全。
