# 任务 4: 实时性与部署优化

任务概览：研究YOLO在嵌入式平台（如Jetson、FPGA）上的实时推理优化方法，满足无人机边缘计算需求。

来源概览：
1. Technical Aspects of Deploying UAV and Ground Robots for Intelligent Logistics Using YOLO on Embedded Systems (PMC, 2025) - 对比YOLOv5和YOLOv8在嵌入式系统上的推理速度、精度
2. Optimization of YOLOv8 for UAV-Based Object Detection (ResearchGate) - YOLOv8在无人机应用中的高精度与实时性能挑战
3. Real-Time Edge Intelligence in UAV for Search-and-Rescue (ACM) - YOLOv5n模型在Raspberry Pi等资源受限平台上的优化
4. Optimizing Object Detection With YOLOv5 for Real-Time Applications (IEEE) - YOLOv5实时应用优化
5. Edge Deployment of YOLO for Real-Time Object Detection (P3MPI) - 边缘部署概念与方法
